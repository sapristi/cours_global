## 1.1 URL

Une URL (*unified resource locator*) est une chaîne de caractères particulière. Elle est constituée de plusieurs parties :

![[request_full.png|600]]
*Tiré de https://developer.mozilla.org/en-US/docs/Learn/Common_questions/Web_mechanics/What_is_a_URL — le site https://developer.mozilla.org est une très bonne référence pour tout ce qui concerne les technologies du web.*

On utilisera une version un peu plus simple :

![[request_simple.png|600]]

- *schema :* détermine le protocole utilisé pour communiquer avec le serveur distant
- *domaine :* identifiant du serveur distant (permet de trouver l'adresse IP associée)
- *ressource* + *paramètres :* chaînes de caractères quelconques (et optionnelles), interprétées par le serveur distant

## 1.2 Requête web (et sa réponse)

Une requête web est un message envoyé d'un ordinateur à un autre. L'URL est un élément essentiel d'une requête, puisqu'elle permet de savoir :
- quel est le serveur à contacter
- quel protocole utiliser

Mais ce n'est pas le seul élément qui constitue une requête.

**Éléments d'une requête :**

| Élément | Description | Exemples |
| ------- | ----------- | -------- |
| **URL** | Détermine le protocole, le serveur à contacter, et permet de passer certains paramètres | `https://some-domain/sub/path?arg1=v1&arg2=v2` |
| **Méthode** | Chaîne de caractères quelconque | `GET`, `POST`, etc. |
| **Headers** | Ensemble de paramètres « clé - valeur » | `User-Agent: Mozilla/5.0`<br>`Accept: text/html`<br>`Cookie: WMF-Last-A...` |
| **Body** | Données quelconques (optionnel) | — |

Une fois la requête envoyée, le serveur distant envoie une réponse, qui contient :

**Éléments d'une réponse :**

| Élément | Description | Exemples |
| ------- | ----------- | -------- |
| **Status code** | Permet de connaître le statut de la requête. Voir https://en.wikipedia.org/wiki/List_of_HTTP_status_codes | `200`, `400`, `500`, etc. |
| **Headers** | Ensemble de paramètres « clé - valeur » | `content-type: text/html`<br>`content-length: 25874` |
| **Body** | Réponse en elle-même — données quelconques | page html, image, donnée json, etc. |

## 2.2 Serveur exemple

Par exemple, en ouvrant le lien suivant http://demo.mmill.eu/rec/bonjour_esgi/?cours=3A , on obtient la réponse :

```text
scheme: http
method: GET
path: /rec/bonjour_esgi/

parameters:
    {

        ]
    }
```
