# 1. Python

> [!abstract] Philosophie
> Python = **interprété, typage dynamique, lisible**. Pas de compilation, pas de déclaration de type obligatoire, l'indentation fait partie de la syntaxe.

- **Interprété :** `python3 script.py` exécute directement. Idéal pour itérer vite en analyse.
- **Typage dynamique :** une variable peut prendre n'importe quel type, le type est vérifié à l'exécution.
- **Indentation obligatoire :** pas d'accolades, un bloc = 4 espaces. Un mélange tabulations/espaces = `IndentationError`.
- **Batteries incluses :** Beaucoup de modules présents dans la lib standard.
- **REPL**: on peut exécuter du code python interactivement.

```text
$ python
Python 3.14.7 (main, Aug 10 2026, 07:46:56) [GCC 16.1.1 20260728] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 + 2
4
>>> "sha256:" + "abc"
'sha256:abc'
```

# 2. Variables et types

## 2.1 Base

```python
n: int = 443
ratio: float = 0.97
service: str = "ssh"
ouvert: bool = True
banniere: str | None = None  # None = "pas de valeur"
```

- `None` : valeur par défaut pour "pas encore connu" (ex. version d'un service non détectée).
- Typage dynamique : `x = 1` puis `x = "scan"` est légal — mais à éviter, ça rend le code illisible.
- **Annotation de variable** (`nom: type = valeur`) : documentation gratuite, ne bloque rien à l'exécution. Dans tout le cours on type les variables des snippets (`str | None` = "str ou None").

## 2.2 Chaînes

Logs, IOC, hash, URL : tout est du texte.

```python
log: str = "Failed password for root from 192.168.1.10"
ip: str = log.split()[-1]          # '192.168.1.10'
print(f"IP suspecte : {ip}")  # f-string : formatage moderne à utiliser

print("root" in log)          # True : test d'appartenance
print(log.lower().startswith("failed"))  # True
```

> [!example] Méthodes à connaître
> `split()`, `strip()`, `lower()`, `startswith()`, `join()`, `in`. On les revoit en parsing de logs (module 7).

# 3. Conteneurs : list, dict, tuple, set

| Type    | Syntaxe              | Usage cyber typique                    |
| ------- | -------------------- | -------------------------------------- |
| `list`  | `["a", "b"]`         | liste d'IP, de ports, de lignes de log |
| `dict`  | `{"ip": "...", ...}` | un événement parsé (champ → valeur)    |
| `tuple` | `(ip, port)`         | paire inséparable, clé de dict         |
| `set`   | `{"a", "b"}`         | dédupliquer des IOC, tester vite `in`  |

```python
ports: list[int] = [22, 80, 443]
evenement: dict[str, str | int] = {"ip": "10.0.0.5", "port": 22, "status": "open"}

# dict : accès + valeur par défaut (évite le crash)
print(evenement.get("version", "inconnue"))

# set : dédupliquer des IOC
iocs: list[str] = ["1.2.3.4", "1.2.3.4", "5.6.7.8"]
print(list(set(iocs)))  # ['1.2.3.4', '5.6.7.8']
```

> [!danger] Piège mutable
> `list` et `dict` sont **mutables** (modifiables sur place), `str` et `tuple` sont **immuables**. Ne jamais utiliser une liste comme valeur par défaut d'une fonction (cf. §5).

# 4. Spécificités Python à maîtriser

## 4.1 Slicing et `in`

```python
s: str = "2026-09-13:auth:failed"
print(s[:10])   # '2026-09-13' : 10 premiers caractères
print(s[-6:])   # 'failed' : 6 derniers

ports: list[int] = [22, 80, 443, 8080]
print(ports[1:3])  # [80, 443]
```

## 4.2 Compréhensions — filtrer en une ligne

```python
lignes: list[str] = ["ok admin", "failed root", "failed guest", "ok admin"]
echecs: list[str] = [l for l in lignes if "failed" in l]
print(echecs)  # ['failed root', 'failed guest']
```

Équivalent à une boucle `for` + `if`, mais plus lisible quand le filtre est simple.

## 4.3 Truthiness et `==` vs `is`

```python
# Faux : False, None, 0, "", [], {}
if not []:
    print("liste vide = faux")

a: str = "abc"
b: str = "abc"
print(a == b)  # True : même valeur
print(a is b)  # à éviter pour les valeurs : teste l'identité, pas l'égalité
```

Règle : `==` pour comparer des valeurs, `is` uniquement pour `is None`.

# 5. Contrôle : `if` / `for`

## 5.1 `if` / `elif` / `else`

```python
code: int = 404
if code == 200:
    print("OK")
elif code in (401, 403):
    print("auth requise")
else:
    print("autre")
```

## 5.2 boucles `for` 

En Python on peut itérer directement sur les éléments:

```python
ports: list[int] = [22, 80, 443]
for port in ports:
    print(f"port {port}")
```

On peut aussi utiliser des indices:
```python
# Quand l'indice sert vraiment : enumerate
for i, ligne in enumerate(open("/var/log/auth.log")):
    pass  # i = numéro de ligne, ligne = contenu

# Quand on veut une plage : range
for i in range(3):  # 0, 1, 2
    print("#" * (i + 1))
```

- `break` : sortir, `continue` : sauter à l'itération suivante.
- `while` : rare en analyse, surtout pour relire un flux jusqu'à épuisement.

> [!note] À retenir
> `for x in collection` + `if x ...` couvre 90 % des scripts d'analyse. Si vous écrivez `for i in range(len(...))`, il y a presque toujours plus simple (`enumerate` ou itération directe).

# 6. Fonctions

```python
def extraire_ip(ligne: str) -> str | None:
    """Renvoie l'IP en fin de ligne de log, ou None si absente."""
    parts: list[str] = ligne.strip().split()
    if not parts:
        return None
    candidat: str = parts[-1]
    # validation minimale : 4 groupes séparés par des points
    if candidat.count(".") == 3:
        return candidat
    return None
```

Points importants quand on écrit une fonction:
- **Type hints** (`ligne: str`, `-> str | None`) 
	sert au type-checker, mais aussi à documenter la fonction
- **Docstring** (`"""..."""`) :
	documente la fonction

# 7. Classes — le minimum vital

Utiles pour modéliser un objet métier (un log parsé, un IOC, une alerte), pas pour tout.

```python
class Alerte:
    ip: str
    regle: str
    vues: int

    def __init__(self, ip: str, regle: str) -> None:
        self.ip = ip
        self.regle = regle
        self.vues = 1

    def revoir(self) -> None:
        self.vues += 1

    def __str__(self) -> str:
        return f"{self.ip} [{self.regle}] x{self.vues}"

a: Alerte = Alerte("1.2.3.4", "brute-force SSH")
a.revoir()
print(a)  # 1.2.3.4 [brute-force SSH] x2
```

- `__init__` = constructeur, `self` = l'instance.
- Règle simple : si une fonction manipule toujours les mêmes 2-3 données ensemble, c'est une méthode d'une classe.

# 8. Gestion d'erreurs

Utile pour ne pas crasher au milieu d'un traitement en batch par exemple:

```python
lignes: list[str] = ["22", "oups", "443"]
for ligne in lignes:
    try:
        port: int = int(ligne)
    except ValueError:
        print(f"ligne ignorée : {ligne}")
        continue
    print(f"port {port}")
```

- `try / except / else / finally` : `else` = si pas d'erreur, `finally` = toujours exécuté.
- Attraper **l'exception précise** (`FileNotFoundError`, `ValueError`), jamais `except:` nu.

# 9. Lire / écrire dans un fichier avec `with`

```python
from pathlib import Path

# lecture sûre : le fichier est toujours refermé
contenu: list[str] = Path("iocs.txt").read_text(encoding="utf-8").splitlines()

# écriture
with open("alertes.txt", "w", encoding="utf-8") as f:
    ips: set[str] = set(contenu)
    for ip in ips:
        f.write(ip + "\n")
```
