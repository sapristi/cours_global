## 2.1 IP + port

- **IP :** adresse de la machine (ex. `127.0.0.1` = localhost).
- **Port :** porte d'entrée vers un service (ex. `22` SSH, `80` HTTP, `443` HTTPS).
- Couple `(IP, port)` = adresse complète d'un service.

## 2.2 TCP vs UDP

| Protocole | Mode             | Garantie               | Usage typique                  |
| --------- | ---------------- | ---------------------- | ------------------------------ |
| `TCP`     | connecté, fiable | ordre + retransmission | SSH, HTTP                      |
| `UDP`     | sans connexion   | rapide, sans garantie  | DNS, streaming, jeu temps réel |

## 2.3 DNS et client-serveur

- **DNS :** annuaire `nom -> IP`. Une erreur DNS en Python = `socket.gaierror`.
- **Client-serveur :** le client `connect`, le serveur `bind + listen + accept` (voir 3.3 ci-dessous).
- **Bannière :** texte renvoyé par un service à la connexion. Bannière verbeuse = fuite d'info (version exposée = **IOC** utile en Blue, piste en Red).
# 3. `socket` en Python

> [!info] Philosophie
> `socket` = lib standard, bas niveau. On manipule des **bytes**, pas des `str`. Tout appel réseau peut bloquer ou échouer : **toujours un timeout**.

## 3.1 Connexion propre avec timeout

```python
import socket

def est_ouvert(host: str, port: int, timeout: float = 2.0) -> bool:
    """Teste un port TCP. Renvoie True si ouvert, False sinon."""
    try:
        with socket.create_connection((host, port), timeout=timeout):
            return True
    except (TimeoutError, ConnectionRefusedError, OSError):
        return False

print(est_ouvert("127.0.0.1", 8000))
```

- `create_connection` gère DNS + `connect` + timeout en une ligne.
- `with` garantit la fermeture, même en cas d'erreur.
- `OSError` couvre `socket.gaierror` et les erreurs réseau (classe parente).

## 3.2 Envoyer / recevoir (bytes)

```python
import socket

def recuperer_banniere(host: str, port: int, timeout: float = 2.0) -> str | None:
    """Se connecte, lit jusqu'à 1024 octets, renvoie la bannière décodée."""
    try:
        with socket.create_connection((host, port), timeout=timeout) as s:
            donnees = s.recv(1024)
    except (TimeoutError, ConnectionRefusedError, OSError):
        return None
    if not donnees:
        return None
    return donnees.decode(errors="replace").strip()


print(recuperer_banniere("127.0.0.1", 8000))
```

- `recv(1024)` = jusqu'à 1024 octets, peut rendre moins — normal en TCP.
- `.decode(errors="replace")` évite le crash sur bytes non-UTF8.

## 3.3 Serveur minimal (pour tester en local)

> [!info] Labo isolé uniquement
> On écoute sur `127.0.0.1` : testable avec les clients 3.1-3.2 ci-dessus. Ne pas écouter sur `0.0.0.0` ni tester une machine sans **autorisation écrite** (**art. 323-1 Code pénal**).

```python
import socket

HOST = "0.0.0.0"  # /!\ Autorise toutes les connections !
# Normalement, on restreint au nom / ip publique, par exemple
# HOST = "exemple.com"

PORT = 8000


def lancer_serveur() -> None:
    """Lance un serveur TCP minimal : banniere + echo, quitte sur BYE."""
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as serveur:
        serveur.setsockopt(socket.SxOL_SOCKET, socket.SO_REUSEADDR, 1)
        serveur.bind((HOST, PORT))
        serveur.listen(1)
        print(f"Ecoute sur {HOST}:{PORT} (Ctrl+C pour arreter)...")
        conn, addr = serveur.accept()
        with conn:
            print(f"Connexion de {addr}")
            conn.sendall(b"COUCOU serveur TP 127.0.0.1\r\n")
            while True:
                donnees = conn.recv(1024)
                if not donnees:
                    break
                texte = donnees.decode(errors="replace").strip()
                if texte == "BYE":
                    break
                conn.sendall(b"ECHO: " + donnees)


if __name__ == "__main__":
    lancer_serveur()
```

- `bind + listen + accept` = côté serveur, miroir du `connect` client.
- `with` sur `serveur` et `conn` : fermeture automatique.
- On parle **bytes** : `sendall(b"...")` / `recv(1024)` / `.decode(errors="replace")`.
- Tester : lancez ce serveur dans un terminal, puis `recuperer_banniere("127.0.0.1", 8000)` dans un autre.
