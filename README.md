## TD en ligne (JupyterLite)

👉 **<https://sapristi.github.io/cours_global/>**

Les notebooks de TD s'ouvrent directement dans le navigateur ( rien à
installer, Python tourne dans le navigateur via JupyterLite/Pyodide).

- La version en ligne est un **énoncé à trous** : les solutions sont retirées
  au déploiement.
- Le travail est enregistré **dans le navigateur**.

Lorsqu'un notebook est édité et sauvegardé dans le navigateur, il ne contiendra pas d'éventuelles mises-à-jour.
Afin de recharger la dernière version, utiliser le bouton "Clear notebook" créé dans la 1ère cellule (! supprime entièrement l'état courant !)
