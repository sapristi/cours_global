### Task 4: TD05 — exercice 3, la classe `SVM` (SGD échantillon par échantillon)

**Files:**
- Modify: `machine_learning/td/05_svm.ipynb` (append)

**Interfaces:**
- Consumes: `Perceptron`, `make_dataset`, `make_axis`, `display_separator`, `plot_data` (Task 3).
- Produces (connus par Task 5) :
  - `class SVM:` dataclass `w: np.ndarray (2,), b: float, lr: float = 0.05, lam: float = 0.05` ; méthodes `z(x) -> float`, `Z(X) -> np.ndarray (N,)`, `output(x) -> int` ($\pm 1$), `fit(X, t, epochs=300) -> SVM` (par échantillon : si $t_i z(x_i) < 1$ → $w \mathrel{-}= r\,(\lambda w - t_i x_i)$, $b \mathrel{-}= r\,(-t_i)$ ; sinon $w \mathrel{-}= r\,\lambda w$ ; ordre mélangé par époques avec un rng local, seed fixe), `marge(X, t) -> float` = $\min_i t_i(w^T x_i + b)/\|w\|$, `supports(X, t) -> np.ndarray` (masque booléen : $t_i(w^T x_i + b) < 1$) ;
  - `show_marge(ax, w, b)` : dessine la bande $w^T x + b = \pm 1$ rempli translucide.

- [ ] **Step 1: Écrire l'énoncé de l'exercice 3 (cellules md)**

Rappel : perceptron $w \mathrel{+}= t_i x_i$ corrige « mauvais côtés » ; SVM corrige aussi les points « dans la marge » ($t_i(w^T x_i + b) < 1$) et tire toujours $w$ vers zéro ($-\lambda w$) ; consigne : classe `SVM` et comparaison avec `Perceptron` sur le même nuage.

- [ ] **Step 2: Écrire le corrigé `class SVM` + affichages (sous `# BEGIN`/`# END`)**

`fit` échantillon par échantillon (style TD01), époques mélangées ; affiche : frontière + bande + quasi vecteurs supports cerclés (masque `supports`), marge chiffrée.

- [ ] **Step 3: Écrire la cellule d'assertions numériques canoniques (corrigée aussi)**

Jeu canonique $X = [[-2,0],[2,0],[0,2]]$, $t = [-1,-1,+1]$ :

```python
svm_can = SVM(np.zeros(2), 0.0, lr=0.1, lam=0.05).fit(X_canonique, t_canonique, epochs=500)
assert np.all(np.sign(svm_can.Z(X_canonique)) == t_canonique)  # prédictions exactes sur le jeu canonique
m = svm_can.marge(X_canonique, t_canonique)
assert m >= 0.8, f"marge trop faible : {m}"                    # solution exacte attendue : marge = 1
assert abs(svm_can.w[0]) <= 0.15                               # séparateur horizontal en solution exacte
```
